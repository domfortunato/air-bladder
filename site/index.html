A Foundry VTT game system for Cairn 2e and Cairn Barebones Edition.

Install GitHub Releases

Air Bladder is a friendly companion system — not the official Cairn system. It gives you verbose 2e backgrounds, character and hireling generation, a marketplace, containers, and Warden-facing roll tables, with minimal automation and a lot of tooltips.

It descends from yochaigal/Cairn-FoundryVTT by Yochai Gal & Oskar Świda, which descends from the Electric Bastionland system and Into the Odd. Air Bladder is the first item in the Gear table on p. 17 of the Cairn 2e Player's Guide.

Install

Requires Foundry VTT v14.

  1. In Foundry's Game Systems menu, click Install System.
  2. Paste this manifest URL and install:
https://github.com/domfortunato/air-bladder/releases/latest/download/system.json

What you get

  • Random or manual generation of both Cairn 2e and Barebones characters — each style can be toggled on or off
  • Barebones sheets support optional homebrew features
  • Warden-authored custom 2e backgrounds — create, preview, lint, and share them across worlds
  • Random or manual generation of hireling sheets
  • A marketplace and containers
  • Warden-facing roll tables — encounters, travel, weather, NPCs, monsters
  • A gallery of 80 character portraits by Jon Aspeheim
  • Tooltips for players, and minimal automation — the rules stay in your hands

Guides

Creating custom backgrounds

Write your own Cairn 2e background — gear, example names, and two d6 question tables — and lint it before you use it.

Sharing custom backgrounds

Hand a background you wrote to another world or another Warden.

Custom portrait gallery

Put your own portrait art into the character generator's gallery.

Generating factions

Roll a faction dossier from the Setting Seeds tables, then let the sheet die deal your canon factions to NPCs and monsters.

Translating — the spreadsheet way

Translate the interface and the game content with no coding and no git.

Translating — the git way

Work directly in the repo with pull requests, the way the Spanish translation is done.

Status

Early, active development. Send feedback and art. The system is being rebuilt on the original's editable-compendium architecture — gear lives in Item compendia a Warden can edit in one place, and character generation and the marketplace reference those packs by name.

Translators welcome. Spanish is the one language with a real translation (74% of the interface and all the game content, by Malecho). Danish, French, German, Polish and Brazilian Portuguese interface files came from the original Cairn system and sit at 15–30%, unmaintained — untranslated text falls back to English, so they work, they're just mostly English. The tooling takes any language; what's missing is people.

Generative-AI art will never appear in this project — ever. The code, on the other hand, was written entirely with Claude Code, using Yochai Gal's original Cairn repo as a base.
