# Cairn compatibility marks

`Cairn_Stamp.jpg` is the "For Use With Cairn" stamp — **the one this system
displays**, on the character sheet and in the top right of the printed page
(user ask 2026-08-16, replacing the badge below on both surfaces at once). It
comes from the same source and carries the same terms as everything else here:
downloaded unmodified from Yochai Gal's own link on
<https://cairnrpg.com/resources/logos/>, 338×218, ship it as it arrived.

`Cairn-2e-Compatible.png` is the official "Compatible with Cairn 2e" badge,
downloaded unmodified from <https://cairnrpg.com/resources/logos/>. **Nothing
references it any more**; it is kept because it is the mark the system shipped
under for its first releases, and because deleting a licensed asset to save
17KB is how the provenance recorded here gets lost.

That page states no bespoke terms, so both marks carry the site's licence —
**CC BY-SA 4.0**, the same licence as the Cairn game text this system
implements. Attribution is to **Yochai Gal**, and is rendered on every character
sheet beneath the mark (see `CAIRN.CompatibleCredit` in `lang/en.json`) and in
the printed page's footer credits.

Ship them unmodified. Recolouring or cropping either would both misrepresent the
mark and lose the ShareAlike-clean provenance recorded here — which is why the
surfaces that display one set a WIDTH and leave the height to follow, and why
`dev:print` measures the rendered box against the file's own aspect: a squashed
render is a crop.

`Cairn-2e-Compatible_white.jpg` is that same badge flattened onto an opaque
white background — the badge artwork itself untouched — because the transparent
PNG nearly vanishes on GitHub's dark theme (`6cf4db3`). Only `README.md` uses
it. As an adaptation of the badge it carries the same CC BY-SA 4.0 licence and
the same attribution to Yochai Gal.
