# Cairn compatibility badge

`Cairn-2e-Compatible.png` is the official "Compatible with Cairn 2e" badge,
downloaded unmodified from <https://cairnrpg.com/resources/logos/>.

That page states no bespoke terms, so the badge carries the site's licence —
**CC BY-SA 4.0**, the same licence as the Cairn game text this system
implements. Attribution is to **Yochai Gal**, and is rendered on every character
sheet beneath the badge (see `CAIRN.CompatibleCredit` in `lang/en.json`).

Ship it unmodified. Recolouring or cropping it would both misrepresent the badge
and lose the ShareAlike-clean provenance recorded here.

`Cairn-2e-Compatible_white.jpg` is that same badge flattened onto an opaque
white background — the badge artwork itself untouched — because the transparent
PNG nearly vanishes on GitHub's dark theme (`6cf4db3`). Only `README.md` uses
it; every in-app surface keeps the unmodified PNG above. As an adaptation of
the badge it carries the same CC BY-SA 4.0 licence and the same attribution to
Yochai Gal.
